TUTORIAL SYSTEM REPO ROBLOX

Tutorial controller is where other client sided scripts input specific tutorial systems or start tutorials. Each tutorial is stored in a module scsript like in tutorialexampletemplate
TutorialControllerServer is for server side verification


Tutorial Example Template is the tutorial shown in the provided video. Setup is the initial function that is played by the tutorial controller when that specific tutorail step is started.

Tutorial Helper is the visual helper used by tutorials for highlighting ui, objects and guide arrows
